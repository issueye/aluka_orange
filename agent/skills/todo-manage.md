# TODO 管理

当用户表达"待办/记得/跟进/帮我记着/回头看"等意图，或当前会话有遗留任务时，参考以下规范使用 TODO 插件工具。

## 工具一览

- `todo_add(text)` — 添加任务（文本即任务内容）。示例：用户说"记得周末发周报" → `todo_add({text:"周末发周报"})`
- `todo_list()` — 列出当前待办与已完成（未完成在前）。用户问"有哪些任务/待办还有多少"时使用。
- `todo_done(id)` — 按编号标记完成（编号来自 todo_list）。示例：完成 #1 → `todo_done({id:1})`
- `todo_clear()` — 清理已完成的任务。

## 行为偏好

1. **积极记录**：当用户承诺、提到"记得/回头/帮我记着/梳理一下"等信号时，主动经 `todo_add` 记录（无需用户说"/todo add"）。
2. **被问及时回答**：用户问"有哪些任务"或让查看待办时用 `todo_list` 回答；完成任务后用 `todo_done`。
3. **对话开始先看**：如 `todo_list` 显示有遗留任务，在空态对话或用户首次消息后，顺带提一句"还有 N 项待办"。
4. **不打扰**：已明确拒绝或上下文无需跟进时不强行记录/提醒。
5. **命令/组件同步**：`/todo add`（输入框命令）与扩展工具共享同一套文件数据（`~/.aluka/agent/data/todo.json`）；输入框上的组件卡反映当前待办（可折叠，点击 ○ 完成）。
