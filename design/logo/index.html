Aluka Orange — 品牌标识提案

为 Aluka 家族的桌面 AI Agent 产品「aluka_orange」设计的三个标识方向。 三者共享同一设计输入，从「家族直系」到「差异化新颖」递进，供混合挑选。

产品身份 · aluka_orange

项目名自带身份关键词「orange」，但当前 UI 是纯中性灰 —— 橙色身份尚未被视觉化，这正是 logo 要补上的空位。

02

三个方向

同一副骨架的三种性格：家族直系 → 实用扁平 → 差异化新颖。

A

橙棱镜

Orange Prism · 家族直系

概念 — 像素级继承母品牌棱镜「A」的几何骨架，只换色谱：青→琥珀、品红→焦橙、深空蓝黑→暖棕黑。一眼即认「Aluka 家族的橙色款」，品牌延续性最大化。

适用 — 启动屏、官网、营销物料等大尺寸场景最有冲击力；16px 下棱面细节会糊成暖色方块（仍可辨识为 A）。

B

橙核

Spark Core · 实用扁平

概念 — 扁平「A」单字标，去掉辉光与多面渐变，只留一个动作：横杠右端的断口是一枚终端光标（caret）。这是「AI Agent / 终端」的产品属性第一次进入字形本身。

适用 — 应用图标的主选方向：16px 托盘下轮廓依然清晰；暖黑 squircle 在深浅桌面壁纸、任务栏里都稳定。另有透明底 mark 版供 UI 内部使用（下见双底测试）。

C

橙光剖面

Citrus Prism · 差异化

概念 — 「orange」的具象转译：一枚抽象的橙子剖面（8 瓣放射、深浅交替），中心白芯里嵌着母品牌的最小棱镜 A —— 果实与晶体的对话。三个方案里唯一的浅底，气质从「工程感」转向「温暖的产品感」。

适用 — 记忆点最强、最不像「又一个开发者工具」的方向；但与母品牌的视觉联系最弱（只靠中心小 A 维持），16px 下剖面退化为一个橙色圆斑。
